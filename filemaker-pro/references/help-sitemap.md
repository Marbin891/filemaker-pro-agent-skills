## Archive and binary documents
Archive: https://help.claris.com/en/claris-help-center/content/archive.html

Append `?fmp` (Pro), `?fms` (Server), `?fmc` (Cloud), `?fmg` (Go), `?cc` (Connect), or `?cs` (Studio) for the source's filtered views.

- FileMaker ODBC and JDBC Guide: https://help.claris.com/en/odbc-jdbc-guide.pdf
- FileMaker Server Custom Web Publishing Guide: https://help.claris.com/en/server-custom-web-publishing-guide.pdf
- Apple Remote Desktop Deployment Script: https://www.claris.com/resources/documentation/docs/fmp_osx_deployment.zip

These binary/PDF resources are not HTML guides. No linked document's contents are bundled merely by listing its URL.
