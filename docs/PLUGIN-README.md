# FileMaker Pro Agent Skills

<p align="center">
  <img src="assets/logo-512.png" alt="FileMaker Pro Agent Skills project logo" width="128" height="128">
</p>

Portable plugin containing five FileMaker development skills:

- `skills/filemaker-pro/` — native calculations, script steps, errors, APIs and
  product behaviour;
- `skills/goya-be-plugin/` — BaseElements functions and patterns;
- `skills/monkeybread-mbs-plugin/` — MBS components, platform and licensing;
- `skills/beezwax-bbox-plugin/` — bBox functions and script steps;
- `skills/fmp-dev-orchestrator/` — routing across the set.

Read each skill's `SKILL.md` before use. The orchestrator selects the smallest
useful set. Reference material is local and read-only; no plug-in binary,
licence key or live FileMaker connection is bundled.

Installation and full documentation: see the repository README.
